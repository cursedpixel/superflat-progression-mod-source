Cursed's (Cur-sid's) Superflat Expansion fills certain gaps in the progression of the Survival Superflat Challenge, as well as making the challenge more accessable. This mod adds a preset that allows generating an ideal superflat world without using multiple versions of the game or file editors.

This mod is begginer freindly! In this mods Advancement tab, it is ordered in *rough* progression order, so if you're lost check the advancements timeline! If not, enjoy the dozens of Superflat specific advancments.

## A Brief List of the Main Features: ##
- ### Superflat Challenge preset ###
- ### Slime Crafting & Blockset ###
- ### New Structures "Emerged Dungeons" bring dungeons to superflat! ###
  - Access to Cocoa Beans
  - Bamboo Seeds, Which give access to Bamboo
- ### Villages now have gravel paths again! ###
  - ### Gravel paths have Suspicious gravel which has LOTS of loot ###
    - Obtainable Loot: Ruby Item, Shipwrecks, Trail Ruins, Cold & Warm Ocean Ruins, Desert Well, Pyramid
- ### Adds Flat All Dimension (Secret Developer World Option) option to World Types ###


Tuff and Calcite are now craftable, Mixing Andesite and Deepslate in an Alternating Square pattern creates 16 Tuff, and using the same pattern with Tuff and Diorite creates 16 Calcite

## Future Plans ##

### Planned - Biome Creation Mechanic ### 
Biomes can now be activated on a by-area basis around a certain amount of trees, blocks or other! Biomes spawn their respective mobs. Depending on which blocks are in a 64x64 block area from the player, that area will be set to the certain biome. \
This makes every extinct and unobtainable mob possible, with heavy effort and a bit of grind from the player.

In Superflat Created Ocean biomes Elder Guardians can rarely patrol, accompanied with 1-2 Guardians, and 2 Scourge of the Sea

Scourge of the Sea \
A Drowned with a Heart of the Sea cyclops-eye that fires Guardian lasers that don't move after being shot. Drops the Heart of the Sea

### Planned - Plant Crossbreeding ### 
Plants can be crossbred to create other plants using a Punnett square \
Used to get previously non-superflat plants

The Sniffer can now dig up Ancient Rose, and Preserved Paeonia, both used for a new dye and for Crossbreeding

### Planned - Slime Sticker Crafting Table ###
The Slime Sticker is used to combine items into unobtainable items. \
- Combining Bonemeal and a Heart of the Sea gives 32x Aquatic Fertilizer that can grow Coral and Coral Fans.
- Combining an Amethyst Block and Chorus Flower Dust (from crafting a Chorus Fruit), you can create Budding Amythyst.
- Crafting any Stone/Deepslate, an ore, and Glass; you create a Decorative ore that can be placed and picked back up with Silk Touch, or mined to drop the single ore and stone back.

### Planned - Patch Reversals ###
